# Plantapp 🌱

A simple and intuitive iOS plant-care companion built to help you keep track of your plants and their watering schedules

## ✨ Features
- **Plant Tracking:** Add and organize your indoor and outdoor plants
- **Care Reminders:** Keep track of watering frequencies and care needs
- **Clean Interface:** Designed with a sleek, user-friendly layout

## 🛠️ Built With
- **Language:** Swift
- **Framework:** SwiftUI
- **Architecture:** MVVM
- **IDE:** Xcode
